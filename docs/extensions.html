Extensions Orbit

Aucune n'est embarquée dans l'application : vous installez seulement ce dont vous avez besoin. Le plus simple est de passer par Orbit, qui télécharge l'archive pour vous — mais chaque archive est aussi téléchargeable ici, puis installable depuis votre ordinateur.

Deux façons d'installer

  1. Depuis Orbit (recommandé) — Réglages → Extensions : la liste ci-dessous y apparaît, et un clic sur « Installer » télécharge puis installe l'extension. Orbit vérifie la taille et l'empreinte de l'archive.
  2. Depuis un fichier — téléchargez le ZIP ici, puis dans Orbit : Réglages → Extensions → Installer depuis un ZIP. Pratique hors ligne, ou pour installer une extension qui n'est pas au catalogue.
